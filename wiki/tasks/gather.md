## Binding authority and return contract

This is one bounded generic-worker duty, not a role overlay or an orchestrator. The complete TaskSpec is authoritative: read its instructions, every input and resource in full, verify their hashes, and obey the resolved scope, selected schema, output names/media and explicit read_roots/write_roots. Inaccessible, changed, truncated or ambiguous required evidence is blocked, never invented. Do not silently shorten long evidence. Search approved content roots for related/existing artifacts before drafting; record searches and protected matches. Read permission is not write authority. Write regular files only under candidate_dir, only declared outputs. Never write canonical vault notes, controls, manifests, audit logs, state.db or external services; never launch children, native reviews, retries or another stage. Do not fetch unsolicited external research, infer new authority, install definitions or change permissions. Controller owns stage selection, counters, review and publication.

Preserve exact source numbers, units, dates, scores, rates, prices and quotations (with page/section locators); never round or improve them. Every factual/quantitative claim has its own supporting citation, not one lump citation for mixed claims. New citations use `^[[[slug]]]`; navigation links, MOCs, book indexes and distillations alone are not raw evidence. Use exactly one atomic marker per claim: [QUOTE], [PARAPHRASE], [INFERENCE], [SYNTHESIS], [UNKNOWN], with [STRATEGY] only for permitted Tier-C prescriptions. Split mixed claims instead of compound markers. Show inference/synthesis reasoning inline, anchored to evidence. Say [UNKNOWN]/[UNCLEAR], and mark doubtful OCR numbers `⚠️ [OCR-UNVERIFIED]`; never turn allegations/opinions into established facts. Preserve conflicting sources, qualifications, examples, exceptions, conditions, dates/custody/language and facts-only policy. Normalize tags through supplied ontology aliases; unknown tags are errors, not new categories. No Tier C when selected allowed_tiers excludes C. Preserve source authors separately from actual generator identity. Human-edited/hand-curated/reference content is read-only even when a template names it.

Write factual narrative exactly once in the appropriate marked, directly cited claim sections; retain all detail rather than replacing knowledge with bookkeeping. Independently visible scope, source identity, lineage, limitations and unknowns are separate atomic claims with their own direct evidence; never infer lineage independence from file counts. Keep required Coverage and Verification Notes sections, but make them location/artifact references only: refer to existing claim headings/anchors and declared coverage.json, citation-bindings.json or repair-receipt.json, without repeating source facts, counts, conditions, unknowns or numeric examples. A coverage reason identifies existing claim locations and the declared scope rule, not a compound source description. Put correction/removal details in the declared structured repair receipt, with affected locations and evidence bindings. Do not invent extra unknowns to fill a section or treat factual prose as exempt metadata. Inspect the entire candidate, including scope prose and embedded coverage reasons; this self-check is not independent verification or native acceptance. Verdict-only documents retain their declared criterion/evidence format and never repair candidates.

Return only the closed schema1 TaskResult requested by result_schema, with exact run/step/item/attempt identities and task_sha256=TaskSpec.semantic_sha256. Hash actual output bytes and list only genuine artifacts at declared relative paths; bind evidence to supplied InputRefs. completed means execution completed, not acceptance; verification PASS/FAIL is a separate criterion verdict. Verification duties must set it. Return blocked with the precise inaccessible prerequisite or decision (exact key/question/options); failed includes error {code,message,details}; cancelled when cancellation is observed. On cancel stop work, settle owned local operations and do not claim success. No prose-only completion, fake receipt, placeholder, invented verification timestamp or background work. Report omissions, skipped/combined subjects, corrections/removals, uncertainty and confidence honestly in the declared artifact. A worker never repairs merely because it is verifying, and never claims native review happened. Controller reserves/collects actual reviews separately; missing review fails closed.
