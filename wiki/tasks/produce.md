# Produce bounded index or note candidates

Produce exactly the assigned parent/index/entity/source-note bundle from complete extraction, schema, templates and inventory. Never choose additional subjects. Book paths are resolved data supplied from book_paths raw_layer/slug_by(author|title)/index_file/chapter_pattern/raw_archive/compilation_layer, including approved custom roots; do not infer root catalog from book_paths.index_file. Use actual titles, chapter identities, ISBN/edition/publisher/date/Amazon/Calibre metadata only when present. Index contains description, complete observed table of contents with chapter/entity links, themes, cross-references and retrieval links. Navigation is not accepted evidence or cross-source synthesis. Preserve short combined frontmatter, backmatter/index relationships, entity page ranges and parent_source links without losing raw units.

Detailed source/topic knowledge belongs in separate type:compilation artifact_role:topic_distill candidates, never an immutable raw overwrite. Retain context, novelty after search, key concepts, explanations, arguments, exact examples/figures, implications explicitly labelled inference, related-note links and contradictions. Image analysis is inline at the source's relevant point, not detached decoration. Main/subsource notes retain selected depth and parent linkage. Entity notes must be actual assigned significant tools/people/organizations or image-book logical entities, not invented missing facts. Existing protected matches become proposals/diagnostics, never changed. Report desired navigation updates for controller; no backlinks/MOC writes. Use distill task for a topic-distillation assignment.

Source-note confidence is high only when all claims are actually checked against clear raw text without ambiguity; medium when most are checked but minor ambiguity/OCR uncertainty remains; low for significant ambiguity, OCR issues, unclear sources or many inferences. Do not claim an independent verifier ran when only producer self-check occurred. Low confidence requires substantive, marked/cited uncertainty claims in the relevant claim section; Verification Notes references their exact locations and declared evidence artifacts without repeating them. Retain correction/removal proposals and exact source evidence in the declared structured receipt, not automatic silent edits to existing notes.

Inaccessible, changed, truncated or ambiguous required evidence is blocked, never invented. Do not silently shorten long evidence. Search approved content roots for related/existing artifacts before drafting; record searches and protected matches. Read permission is not write authority. Write regular files only under candidate_dir, only declared outputs. Never write canonical vault notes, controls, manifests, audit logs, state.db or external services; never launch children, native reviews, retries or another stage. Do not fetch unsolicited external research, infer new authority, install definitions or change permissions. Controller owns stage selection, counters, review and publication.

Preserve exact source numbers, units, dates, scores, rates, prices and quotations (with page/section locators); never round or improve them. Every factual/quantitative claim has its own supporting citation, not one lump citation for mixed claims. Use exactly one atomic marker per claim: [QUOTE], [PARAPHRASE], [INFERENCE], [SYNTHESIS], [UNKNOWN], with [STRATEGY] only for permitted Tier-C prescriptions. Split mixed claims instead of compound markers. Show inference/synthesis reasoning inline, anchored to evidence. Preserve conflicting sources, qualifications, examples, exceptions, conditions, dates/custody/language and facts-only policy. Inspect the entire candidate, including scope prose and embedded coverage reasons; this self-check is not independent verification or native acceptance.
