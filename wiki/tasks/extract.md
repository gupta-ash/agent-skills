# Capture raw evidence

Acquire only the exact source/linked scope already authorized in instructions. Preserve supplied binary originals and actual local response bytes/transcript; an interpretation never replaces originals. Use supplied existing extractor entrypoints, argv arrays and candidate output paths; unavailable dependency/source/transcript blocks instead of installing or inventing. Reddit: retain post, all available comments, metadata, content links and images. YouTube/video/course/podcast: require a real accessible supplied/extracted transcript; retain description, provenance and relevant thumbnail text/data, no invented audio transcription or DRM/account automation. Article/Substack/X: preserve actual fetched body and metadata, all relevant outbound links and observed response bytes. TXT/MD/raw text: keep verbatim evidence; missing required title/topic is a decision, not a guess. DOCX/HTML/Word HTML/MHTML/PDF: preserve text, extraction metadata, inline-image positions and original. EPUB2/3/MOBI/AZW3: retain real extractor chapters and full content_path files, conversion provenance and Calibre metadata/library selection. Scanned PDF detection uses actual PyMuPDF sampled-first-ten-pages total <100 characters; render/read page images, do not claim a zero-text test. Never substitute extraction count for source metadata.

The controller independently enumerates every expected page/chapter/section/transcript/image unit and supplies immutable selected capture-scope.json (the current capture inventory) as read-only evidence: stable u000001 source-order unit IDs, original locator/kind, expected and produced paths, actual hashes, missing/unavailable/truncation diagnostics and explicitly declared scope exclusions. Preserve that exact enumeration in declared raw-note-map.json and capture-fidelity.json; do not rewrite the inventory or produce undeclared outputs. Retain full chapter bodies at their supplied content_path, original chapter numbers (Roman/English/numeric are not file ordinals), unnumbered/appendix subjects, combined frontmatter and backmatter accounting. A short combined navigation note does not exclude its raw units.

Copy each output's immutable assigned `ingested`, `source_hash`, `source_hash_kind` and `source_hash_algorithm` exactly. New acquisition snapshots use the original byte hash: `source_hash` is 64 lowercase hexadecimal characters without a `sha256:` prefix, `source_hash_kind: bytes`, `source_hash_algorithm: sha256`. The generated note's normalized-body `content_hash` is a separate `sha256:`-prefixed value; never substitute its spelling or hash domain for acquisition provenance.

Read every substantive image together with preceding/following source text. Preserve position/context and exact visible text, axes, units, labels, values/trends, chart data missing from prose, diagram components/connections/flows, screenshot code/settings/UI and unified slide content. Disclose OCR uncertainty. Decorative-only skips require reason (small icons <50x50, spacers, navigation/ad decoration); when uncertain process it. Image-only books group actual consecutive page ranges into explicit logical entity subjects, retaining every page identity.

Extract unique content URLs, excluding nav/ads/share links. Follow only controller-selected depth0/1/2 and bounded link subjects; record unfetched/deeper/unavailable links and reasons; do not silently choose five from >10 or broaden scope. Archive content only as candidates; controller performs any authorized Wayback intent and local response archive publication. No automatic mutation retry or ClickUp action. Return metadata and truthful archive failures, never nonexistent save-archive commands.

## Binding authority and return contract

This is one bounded generic-worker duty, not a role overlay or an orchestrator. The complete TaskSpec is authoritative: read its instructions, every input and resource in full, verify their hashes, and obey the resolved scope, selected schema, output names/media and explicit read_roots/write_roots. Inaccessible, changed, truncated or ambiguous required evidence is blocked, never invented. Do not silently shorten long evidence. Search approved content roots for related/existing artifacts before drafting; record searches and protected matches. Read permission is not write authority. Write regular files only under candidate_dir, only declared outputs. Never write canonical vault notes, controls, manifests, audit logs, state.db or external services; never launch children, native reviews, retries or another stage. Do not fetch unsolicited external research, infer new authority, install definitions or change permissions. Controller owns stage selection, counters, review and publication.

For a TaskSpec-assigned immutable raw capture, apply the [Source Note contract](../canonical-schema.md#source-note-frontmatter-contract), not the generated-claim annotation rules below. Preserve source-owned syntax and bind the supplied original/unit provenance; generated topic knowledge remains a separate task and artifact.

Keep the required common frontmatter from the supplied source-note template, even for verbatim raw captures: `vault`, actual generator `author`, `pipeline_id`, `status: draft`, `last_verified: null`, `freshness`, `confidence: low|medium|high`, and `human_edited: false`. Choose confidence from the actual capture quality; do not omit it because the body is raw evidence.

Emit only tags allowed by the selected vault's resolved ontology. An explicit ingestion `--topic` selects the output topic; it does not register a new `topic/` tag. If that topic is absent from the resolved topic/alias declarations, omit its topic tag and retain the topic in its metadata/path; use the permitted domain/type/vault tags instead. Never invent or modify schema declarations to make a tag valid.


Preserve exact source numbers, units, dates, scores, rates, prices and quotations (with page/section locators); never round or improve them. Every factual/quantitative claim has its own supporting citation, not one lump citation for mixed claims. New citations use `^[[[slug]]]`; navigation links, MOCs, book indexes and distillations alone are not raw evidence. Use exactly one atomic marker per claim: [QUOTE], [PARAPHRASE], [INFERENCE], [SYNTHESIS], [UNKNOWN], with [STRATEGY] only for permitted Tier-C prescriptions. Split mixed claims instead of compound markers. Show inference/synthesis reasoning inline, anchored to evidence. Say [UNKNOWN]/[UNCLEAR], and mark doubtful OCR numbers `⚠️ [OCR-UNVERIFIED]`; never turn allegations/opinions into established facts. Preserve conflicting sources, qualifications, examples, exceptions, conditions, dates/custody/language and facts-only policy. Normalize tags through supplied ontology aliases; unknown tags are errors, not new categories. No Tier C when selected allowed_tiers excludes C. Preserve source authors separately from actual generator identity. Human-edited/hand-curated/reference content is read-only even when a template names it.

Write factual narrative exactly once in the appropriate marked, directly cited claim sections; retain all detail rather than replacing knowledge with bookkeeping. Independently visible scope, source identity, lineage, limitations and unknowns are separate atomic claims with their own direct evidence; never infer lineage independence from file counts. Keep required Coverage and Verification Notes sections, but make them location/artifact references only: refer to existing claim headings/anchors and declared coverage.json, citation-bindings.json or repair-receipt.json, without repeating source facts, counts, conditions, unknowns or numeric examples. A coverage reason identifies existing claim locations and the declared scope rule, not a compound source description. Put correction/removal details in the declared structured repair receipt, with affected locations and evidence bindings. Do not invent extra unknowns to fill a section or treat factual prose as exempt metadata. Inspect the entire candidate, including scope prose and embedded coverage reasons; this self-check is not independent verification or native acceptance. Verdict-only documents retain their declared criterion/evidence format and never repair candidates.

Return only the closed schema1 TaskResult requested by result_schema, with exact run/step/item/attempt identities and task_sha256=TaskSpec.semantic_sha256. Hash actual output bytes and list only genuine artifacts at declared relative paths; bind evidence to supplied InputRefs. completed means execution completed, not acceptance; verification PASS/FAIL is a separate criterion verdict. Verification duties must set it. Return blocked with the precise inaccessible prerequisite or decision (exact key/question/options); failed includes error {code,message,details}; cancelled when cancellation is observed. On cancel stop work, settle owned local operations and do not claim success. No prose-only completion, fake receipt, placeholder, invented verification timestamp or background work. Report omissions, skipped/combined subjects, corrections/removals, uncertainty and confidence honestly in the declared artifact. A worker never repairs merely because it is verifying, and never claims native review happened. Controller reserves/collects actual reviews separately; missing review fails closed.
