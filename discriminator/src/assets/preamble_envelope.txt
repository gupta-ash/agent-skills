  {
    "schema_version":      "review-envelope/2",
    "verdict":             <string>,
    "summary":             <string>,
    "findings":            [ <finding>, ... ],
    "next_steps":          [ <string>, ... ],

  }

`schema_version` is that literal string and nothing else. `artifact_class_echo` is the artifact class named by the contract appended below, copied VERBATIM.
